# Airway input

Generate the count matrix and sample metadata from the Bioconductor `airway` package with `Rscript scripts/R/prepare_airway.R` from the project root. The package contains gene-level counts from four human airway smooth muscle cell lines, each untreated and treated with dexamethasone. Preserve its citation and do not interpret this small experiment as clinical treatment evidence.

Source: https://bioconductor.org/packages/airway/ ; original study: Himes et al., PLOS ONE 2014, DOI 10.1371/journal.pone.0099625.
